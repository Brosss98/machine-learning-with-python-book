Publication and versioning¶

This book is published online, one chapter at a time. Releases are numbered with semantic versioning (MAJOR.MINOR.PATCH). Versions below 1.0.0 are incomplete: new chapters are added, and existing ones may be revised. Version 1.0.0 will be the first release containing the complete book. The version number appears on this page and on the cover, so that any reference to the book can point to a precise state of the text.

How this book is produced¶

The book is written as Jupyter notebooks and built with Jupyter Book. All code is executed on the author’s computer, and the published website is a set of static files that already contain every output and figure: no computation takes place when you visit the site. Chapter 1 explains how to reproduce this process on your own machine.
