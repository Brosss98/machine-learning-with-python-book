# Machine Learning with Python: From Linear Algebra to Deep Learning

*A Hands-On Mathematical Guide with Jupyter Notebooks, scikit-learn and PyTorch*

**Author:** Mario Medone · **Version:** 0.8.0 (work in progress, one chapter at a time) · **Year:** 2026

A university-level textbook for students who know linear algebra and calculus and want to enter machine learning with confidence. Every chapter combines intuition, step-by-step mathematics, Python code on real datasets, worked examples, and exercises of increasing difficulty (manual and computational).

- **Read online:** <https://brosss98.github.io/machine-learning-with-python-book/>
- **Report errors or suggest improvements:** <https://github.com/Brosss98/machine-learning-with-python-book/issues>

## Run the notebooks on your computer

```bash
git clone https://github.com/Brosss98/machine-learning-with-python-book.git
cd machine-learning-with-python-book
python -m venv .venv
source .venv/bin/activate          # Windows (PowerShell): .venv\Scripts\Activate.ps1
pip install -r requirements.txt
jupyter lab
```

Then open a notebook from the `chapters/` folder. The full instructions, including how to build the book as a website and publish it on GitHub Pages **without any computation on GitHub**, are in the [Setup Guide](chapters/ch01_setup_guide.md).
