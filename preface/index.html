Preface

Why this book¶

Machine learning is usually taught in one of two ways. In the first, it is a collection of recipes: import a model, call fit, call predict, and hope for the best. In the second, it is an abstract theory in which the connection with practice is hard to see. This book sits between the two. It assumes that you already know linear algebra and calculus, and it uses them as the language in which machine learning is explained and then checks every statement with code.

For a reader with that background, most of machine learning is less foreign than it first appears. Ridge regression is a linear system with one small modification. Principal component analysis is the singular value decomposition applied to centered data. Training a neural network is the chain rule applied systematically to a long composition of functions. The aim of this book is to make such connections explicit, to explain the intuition behind each formula, and to let you verify the result on a computer.

Who this book is for¶

The book is written for university students who are starting out in machine learning. It assumes:

  • Linear algebra: vectors, matrices, dot products, eigenvalues and eigenvectors, and the singular value decomposition.

  • Calculus: derivatives, partial derivatives, gradients, and the chain rule.

No previous knowledge of machine learning is required. Some familiarity with programming helps. Chapter 2 reviews the Python tools used throughout the book (NumPy, pandas, and matplotlib) together with the small amount of probability that the later chapters need. Advanced mathematics, such as measure theory, is not required, and proofs are given only when they help to build intuition.

What you will find¶

Every technical chapter is built around the same ingredients:

  1. Learning objectives and intuition, so that you know where the chapter is going and why.

  2. Mathematical formulation and derivations, written step by step in a way that explains each manipulation.

  3. Figures generated by Python code that you can run and modify.

  4. Hands-on implementation on real datasets from standard libraries such as scikit-learn, seaborn, and torchvision.

  5. Worked examples solved both by hand and in code, so that the two can be compared.

  6. Exercises of increasing difficulty, divided into manual (analytical) exercises and Python (computational) exercises. They are meant to be challenging but accessible.

The book follows a practice-first approach. Concepts are introduced together with the code that implements them, and the datasets are real ones. Each chapter is a Jupyter notebook, so you can execute it from beginning to end on your own computer.

Roadmap¶

The book is organized in five parts.

  • Part I, Foundations (Chapters 1–3). What machine learning is, how to set up your environment, the Python and probability tools used throughout, and statistical learning theory, the framework that tells us what it means for a model to learn and to generalize.

  • Part II, Classical Supervised Learning (Chapters 4–11). Nearest-neighbor methods and the bias–variance trade-off, cross-validation and hyperparameter tuning, regularized least squares and logistic regression, stochastic gradient descent, support vector machines, kernels and the representer theorem, sparsity and feature selection (OMP, Lasso, Elastic Net), and decision trees and ensembles.

  • Part III, Unsupervised Learning (Chapters 12–13). Clustering (k-means, vector quantization, spectral clustering, and how to choose the number of clusters), and dimensionality reduction with SVD, PCA, and kernel PCA.

  • Part IV, Deep Learning (Chapters 14–21). Neural network fundamentals, backpropagation and the practice of training deep networks, convolutional networks and their applications, recurrent networks (RNN, LSTM, GRU), attention and transformers, autoencoders and GANs, and graph neural networks.

  • Part V, Decisions and Modern AI (Chapters 22–23). Reinforcement learning with Markov decision processes, Monte Carlo methods, and temporal-difference learning, followed by large language models, modern architectures, AI agents, and future directions.

The book closes with conclusions, appendices (a math cheat sheet, a Python cheat sheet, solutions to the exercises, and a glossary), and a bibliography.

Suggested reading paths¶

If you are following a full course, read the chapters in order: each one builds on the previous ones. If your main interest is deep learning, a faster route is to read Chapters 1–3 and 5–7, which introduce the setup, the learning framework, evaluation, linear models, and gradient-based optimization, and then to move to Part IV, returning to the classical methods later. In either case, do the exercises: the notebooks are designed to be changed and re-run, and that is where most of the learning happens.

A note on rigor¶

The book aims to be mathematically honest without being heavy. When a result is stated without proof, the text says so and indicates where to find the proof, and the bibliography collects references for readers who want to go further. When a simplification is made for the sake of clarity, it is flagged as such.
